## Reading the tables above
Three things the generated sections do not say for themselves.

**The colour table shows light-theme values only.** This app ships two
themes, and the profile knows it — 25 tokens are recorded as themed. But the
table prints one value per token, and the one it picked is light. `--accent`
reads `#1908DF` above; in dark it is `#4b3bf5`. Both live in
`frontend/src/styles/dashboardTheme.jsx`, the dark block first (`:root`) and
the light block second (`:root.light`). Check the source before trusting a
colour here, and remember any contrast check run against this table has only
tested half the app.

**Four tokens are filed under Typography that are not typography.**
`--reg-text`, `--reg-text-secondary`, `--reg-sidebar-text` and
`--reg-sidebar-active-text` are colour aliases — their values are
`var(--text)` and `var(--accent)`. They landed there because the grouping is
by name and their names contain "text". The project has no typography tokens
at all: no font-family, no font-size, no line-height.

**Four groups are empty: spacing, sizing, radius and motion.** That is not a
detection miss — the project genuinely has no tokens for them. Every gap,
width, corner and transition in the codebase is a literal. Audits will
suppress length checks for these groups, so they will not be flagged and
they will not be enforced.

## Where the tokens actually live
Not in a stylesheet. `frontend/src/styles/index.css` defines zero custom
properties. All 53 are inside injected `<style>` blocks in three `.jsx`
files:

| File | Tokens |
| --- | --- |
| `frontend/src/styles/dashboardTheme.jsx` | 44 — the shared theme, both modes |
| `frontend/src/pages/dashboards/admin/AdminDashboard.jsx` | 62 — admin's own copy |
| `frontend/src/pages/dashboards/registrar/shared/ui.jsx` | 21 — the `--reg-*` aliases |

`styling.tokenSource` had to be set by hand to point at these, and is
recorded in `resolvedByHuman` so detection carries it forward.

That admin file holding its own 62 is worth noting: it re-declares tokens
the shared theme already defines, which is how a second source of truth
starts.
